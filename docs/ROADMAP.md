# EVIDA — Roadmap experimental

- **v0.1.0 — Fundação:** C++26, núcleo, API local, SQLite, interface, testes.
- **v0.2.0 — Corpus:** leitura PDF, catálogo, manifesto SHA-256, proveniência por página.
- **v0.3.0 — Extração:** entidades, observações, taxonomia e séries com revisão humana.
- **v0.4.0 — Redes:** grafos de coocorrência, similaridade e sensibilidade ao limiar.
- **v0.5.0 — Episódios:** sequências, censura temporal, dossiês e contestabilidade.
- **v1.0.0 — Validação:** comparação com pipeline legado, auditoria e implantação segura.

Critério de aceite de cada etapa: teste de domínio + teste de API/UI + amostras
rastreadas. Propostas de LLM nunca assumem status de evidência validada.
